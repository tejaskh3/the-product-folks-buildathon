# Curio — product notes (raw, not final)

Ideas collected from 2026-10-06. Items marked **Decided** are settled; everything else waits for a proper planning pass. Don't build from this directly.

## Models
- Anthropic credits ran out. Use **OpenRouter** for models.
- Users can bring their own key (BYOK), stored **encrypted in Supabase**.
- **Decided:** BYOK supports OpenRouter only for now. Other providers later.
- Show every model call per user (date, paper, step, model, tokens, cost, which key paid) so users can see their key isn't used for anything else.

## Pricing (USD)
- **Decided:** prices are in USD.
- **Free:** 2 papers total, ever (**Decided**).
- **BYOK:** user's OpenRouter key plus a platform fee. Unlimited papers, full library. **$2/month** (**Decided**).
- **Starter:** our model, 10 papers/month, **$5/month** (**Decided**).
- **Pro:** our model, 30 papers/month, **$10/month** (**Decided**).
- **Decided:** "click deeper" does not count as a paper. No visible cap, but a generous hidden daily limit on our key (plan review, OV-6).
- Payments through **Dodo Payments**: hosted checkout, a webhook sets the plan.
- If a plan lapses, papers already generated stay readable and the library stays free.
- "Video explanations coming soon" teaser, with a notify-me button.

## Library
- Famous 10–20 papers, generated by us with Claude Code (no API spend).
- Free to read for everyone, no sign-in needed.
- **Public comments** on library papers.
  - **Decided:** only signed-in users can comment.
  - **Decided:** comments are moderated. Anyone can report a comment; reports go to a small admin dashboard (the user will build it).
  - **Decided:** a comment hides automatically after 3 reports; the admin can restore or delete it.
- ~~Clone to ask~~ **Changed 2026-10-07 (plan review):** no cloning. The library paper stays as one shared copy; each user's questions are stored privately on top of it.
  - **Decided:** reading a library paper is free. The first question or click deeper on it counts as one paper; after that it's free like any paper the user owns. If the library paper already has the diagram they asked for, it's served free.
- Maybe later: popular questions, collected anonymously from what users asked.

## Feedback floater
- Bottom-right on every page. Three tabs: Feedback, Feature request, Request a paper (arXiv link).
- Paper requests feed the library queue.

## Reading tools
- **Favorite** ★: a whole paper.
- **Bookmark** 🔖: a spot inside a paper (PDF page, walkthrough scene or diagram).
- **Highlight** 🖍: selected text in the **PDF and in the narration**. Select text to get a menu: Highlight (colors) / Note / Ask Curio / Copy.
- **Questions**: store every question a user asks; "Your questions" row in the paper.
- **Decided:** notes, highlights and bookmarks are private only.
- **Notes panel** per paper: highlights, bookmarks and questions in reading order, jump to each, export to Markdown.
- **Shelf tabs:** Library · My papers · Favorites · Bookmarks · History (searchable).
